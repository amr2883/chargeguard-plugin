# ChargeGuard - Quick Setup Guide

## 1. Installation
- Upload the `woocommerce-chargeguard` folder to `/wp-content/plugins/`.
- Activate the plugin from WordPress Admin > Plugins.

## 2. Configuration
- Go to WooCommerce > Settings > ChargeGuard.
- Enter your API Key and Merchant ID (provided in your welcome email).
- Save changes.

## 3. Verification
- Visit your store's checkout page. The ChargeGuard firewall is now active.
- To test, try to checkout with a disposable email (e.g., anything@mailinator.com). The order should be blocked.

## Need Help?
- Reply to your welcome email or contact support@chargeguard.app.
